# OpenMRS Security Documentation

This repository is the canonical, version-controlled home for the OpenMRS community's security policies, processes, and guidance. Documents here are maintained through pull requests and reviewed by the OpenMRS Security Group.

> **Reporting a vulnerability?** Do **not** open an issue here. Email **security@openmrs.org** or use [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on the affected repository. See our [vulnerability management policy](https://openmrs.atlassian.net/wiki/spaces/docs/pages/25477259/OpenMRS+Security+101+Policies+Vulnerability+Management) for what to expect.

## Why this repository exists

OpenMRS security documentation has historically lived across the wiki, Talk, and individual repositories. This repository consolidates policy-level documents in one reviewable, versioned place — following the pattern of projects like [Kubernetes](https://github.com/kubernetes/committee-security-response) and the [Eclipse Foundation security handbook](https://github.com/eclipse-csi/security-handbook). Where wiki pages and this repository conflict, this repository is authoritative for policy; the wiki remains the home for tutorials and implementation guidance.

## Contributing

Improvements are welcome via pull request. Substantive policy changes require review by the Security Group. Discussion happens on [OpenMRS Talk](https://talk.openmrs.org/) — please do not raise undisclosed vulnerabilities in public threads.
